🍣 Baozi Store — Java

 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas, com o objetivo de colocar em prática conhecimentos de programação Java e desenvolvimento Back-end.

A aplicação consiste em uma API para gerenciamento de pedidos, permitindo realizar operações de cadastro, consulta, atualização e exclusão de registros.

O desenvolvimento proporcionou experiência prática com a estruturação de uma API, lógica de programação, requisições HTTP e testes de funcionalidades.

 🚀 Funcionalidades

- Cadastrar pedidos: adicionar novos registros.
- Consultar pedidos: visualizar informações cadastradas.
- Atualizar pedidos: modificar registros existentes.
- Excluir pedidos: remover registros.
- Testar requisições: verificar o comportamento da API, incluindo respostas para registros inexistentes.

 🛠️ Tecnologias utilizadas

- **Java:** linguagem utilizada no desenvolvimento.
- **Postman:** ferramenta para testar as requisições e respostas da API.
- **API REST:** arquitetura utilizada para comunicação entre cliente e servidor.
- **HTTP:** utilização dos métodos GET, POST, PUT e DELETE.

 📚 Conhecimentos aplicados

Durante o desenvolvimento deste projeto, foram trabalhados conceitos como:

- Programação orientada a objetos.
- Desenvolvimento Back-end.
- Operações CRUD (Create, Read, Update, Delete).
- Manipulação de requisições e respostas HTTP.
- Testes e identificação de erros.
- Organização e estruturação de código Java.

 🎯 Objetivo

Consolidar os conhecimentos adquiridos durante a graduação, desenvolvendo habilidades práticas em programação Java, criação de APIs e testes de aplicações.

Este projeto representa uma etapa do meu aprendizado e desenvolvimento profissional na área de Tecnologia da Informação.
